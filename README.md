# Telegram Store Bot — Railway

## Required Railway Variables
- `BOT_TOKEN`: the NEW token generated by BotFather (never commit it).
- `DATABASE_PATH`: `/data/users.db` (recommended when a Railway Volume is mounted at `/data`).

## Deploy
1. Upload these files to a private GitHub repository.
2. Create a Railway project from that repository.
3. Add a Railway Volume and mount it at `/data`.
4. In Railway → Variables, set `BOT_TOKEN` to the newly generated bot token.
5. Keep `DATABASE_PATH=/data/users.db`.
6. Run one replica only; Telegram polling should not run in multiple replicas.

## Important database note
This source does not define the `categories`, `products`, `orders`, or
`order_items` table schemas. It assumes those tables already exist in the
SQLite database used by the original bot. Migrate/upload the existing
`users.db` to the Railway Volume at `/data/users.db` before launch.
Without it, store and order features will fail. Do not commit the database
to public GitHub.

`welcome_banner.png` is optional. Place it beside `bot.py` if desired.
The bot now continues normally when it is absent.
